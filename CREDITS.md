# Credits

OpenSH is based on [nlsh](https://github.com/junaid-mahmood/nlsh) by Junaid Mahmood,
and has since been extended with pluggable providers (Groq, Gemini, OpenAI-compatible
endpoints, Ollama), cross-platform (PowerShell/Bash/Zsh) prompting, file and history
context, a destructive-command safety guard with explain-before-run, installers and
release builds.
