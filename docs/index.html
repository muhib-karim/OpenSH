One file. Your model. Your shell.

OpenSH is a single Python file that uses only the standard library. Ordinary input such as git status runs as typed with no API call; English goes to the model you picked.

  1. Shell auto-detected

    PowerShell on Windows, zsh or bash from $SHELL elsewhere. Override with --shell.

  2. Explain before run

    --explain shows what a command does and why it was flagged, then asks. --dry-run never runs anything.

  3. Copy and history

    --copy puts the command on your clipboard; input history survives restarts and never stores lines that look like keys.

Install

Needs Python 3.10 or newer. The installer puts OpenSH in ~/.opsh and adds opsh to your PATH. Prefer a binary? Grab one from the latest release.

irm https://raw.githubusercontent.com/muhib-karim/OpenSH/main/install.ps1 | iex

Run in PowerShell. Add pyreadline3 for arrow-key history.

curl -fsSL https://raw.githubusercontent.com/muhib-karim/OpenSH/main/install.sh | bash

Commands are generated for zsh unless your login shell is bash.

curl -fsSL https://raw.githubusercontent.com/muhib-karim/OpenSH/main/install.sh | bash

For --copy, install wl-copy, xclip or xsel.

A guard between the model and your disk

Every generated command is checked against 60+ rules before it runs. Rules match where a command actually starts, so cat shutdown.log is fine and sudo shutdown is not. 135 paired tests keep it from being too loose or too jumpy.

The guard is a seatbelt, not a sandbox: it lowers the risk, it cannot prove a command is safe. Commands you type yourself run as typed.

Bring your own model

Pick one with !auth or --provider. Keys live in ~/.opsh/.env or your environment, are never printed, and are scrubbed from error messages. Requests time out and retry on rate limits.

groq
Default. Fast free tier, llama-3.3-70b-versatile.
gemini
Google AI Studio key, gemini-2.5-flash.
openai
Any OpenAI-compatible URL: OpenAI, OpenRouter, LM Studio, vLLM.
ollama
Local models. No key, nothing leaves your machine.
mock
Offline and deterministic, for tests and demos.
