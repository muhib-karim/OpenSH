# OpenSH v0.4.0 design

## Intent
OpenSH is a public showcase CLI. v0.4.0 makes it safer, provider-agnostic and better tested, without
giving up what makes it easy to adopt: one Python file, standard library only, bring your own key.

## Goals
1. **Safety guard**: rule table with a reason per rule, matched only at command position (so
   `cat shutdown.log` is not a shutdown), covering bash, zsh, PowerShell and cmd. 100+ table-driven
   destructive/benign test pairs. Explain-before-run mode (`--explain`, `!explain`) shows what a
   command does and why the guard flagged it before anything runs.
2. **Providers**: a small `Provider` interface with Groq, Gemini, any OpenAI-compatible endpoint
   (user config), local Ollama and an offline `mock` provider. Shared HTTP helper with timeout,
   retries with backoff on 429/5xx/network errors and `Retry-After`. Keys only from env or `.env`;
   redacted from every error message; Gemini key moves from the URL to a header.
3. **UX**: shell auto-detect (`$SHELL`, `--shell`, `OPENSH_SHELL`), persistent history file,
   `--dry-run`, `--explain`, `--copy` (clipboard), `--help` examples and a man page (`docs/opsh.1`).
4. **CI**: ruff (lint + format), mypy, unittest under coverage (>= 85%) on Ubuntu/macOS/Windows,
   gitleaks, CodeQL, Dependabot. Release workflow tests first, builds binaries on tag, smoke-tests
   them and publishes checksums.
5. **Docs**: README refresh (badges, demo SVG, per-OS install, guard table, provider config,
   mermaid architecture), landing page refresh, CHANGELOG, SKILLS_USED, TASKS, HANDOFF.

## Non-goals
- No sandboxing; the guard stays a seatbelt.
- No third-party runtime dependencies, no package split (installers copy only `opsh.py`).

## Anti-goals
- Changing where or how settings are stored. `config.json` only gains optional keys
  (`model`, `base_url`, `api_key_env`, `timeout`, `retries`, `history`); `.env` is unchanged.
- Breaking existing configs: `{"provider": "groq"}` and `{"provider": "gemini"}` keep working.

## Calls made by the builder (no questions were asked; frozen task)
- Single file kept; the code is organised in sections instead.
- Tests converted from pytest to stdlib `unittest` (task requirement); `coverage` is a CI-only tool.
- Real environment variables now win over `.env` values (was the other way round).
- Minimum Python raised from 3.9 (end of life) to 3.10.
- History file lives next to the config (`~/.opsh/history`); lines that look like secrets are not saved.
